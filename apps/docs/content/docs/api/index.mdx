| Package | Use it for | Reference |
| --- | --- | --- |
| `@glucoseiq/core` | Analytics, ingestion, connectors, interoperability, and SVG rendering | [Core API](/docs/api/core) |
| `@glucoseiq/react` | React hooks, live view models, and SVG components | [React API](/docs/api/react) |
| `@glucoseiq/tokens` | Fixed presentation thresholds, palettes, glyphs, and CSS variables | [Tokens API](/docs/api/tokens) |
